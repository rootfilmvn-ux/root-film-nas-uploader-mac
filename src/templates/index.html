📖 HƯỚNG DẪN SỬ DỤNG NHANH (V1.0.7)
Quy trình 3 bước gửi dữ liệu ngầm siêu tốc, tự động kiểm đếm file lên NAS
Bước 1: Dán Link Request NAS & Mật khẩu (nếu có)
• Dán đường link nhận dữ liệu vào ô Đường dẫn File Request. Nếu link có mật khẩu bảo vệ, điền mật khẩu vào ô 🔐 Mật khẩu Link để ứng dụng tự động mở khóa.
Bước 2: Chọn File lẻ hoặc cả Thư mục (Folder)
• Bấm 📄 Chọn File hoặc 📂 Chọn Folder để chọn dữ liệu từ máy Mac. Hệ thống tự động đếm chính xác tổng số file.
Bước 3: Điền Tên dự án & Bắt đầu tải ngầm lên NAS
• Nhập Tên dự án rồi bấm 🚀 BẮT ĐẦU TẢI DỮ LIỆU LÊN NAS. Ứng dụng sẽ tự động gắn nhãn Tên dự án (Số file files) và truyền tải ngầm trực tiếp lên NAS.
